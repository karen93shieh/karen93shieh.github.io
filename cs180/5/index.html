Project 5: The Power of Diffusion Models

Exploring DeepFloyd IF, forward/denoising processes, flow matching on MNIST, and fun applications like inpainting, visual anagrams, and hybrid images.

  • Date: Nov 2025
  • Course: CS180

Project Overview

In Part A of Project 5, I experiment with a pre-trained text-to-image diffusion model (DeepFloyd IF) to understand how diffusion-based generative models work in practice. I implement the forward diffusion process, several denoising schemes, and then apply them to tasks like image-to-image translation, inpainting, visual anagrams, and hybrid images.

In Part B, I build diffusion-style models from scratch on MNIST. I first implement and train a single-step UNet denoiser, and then extend it into a time-conditioned flow matching model, with optional class-conditioning and bells & whistles for improved generation quality.

1.1 — Implementing the Forward Process

The forward process adds noise to a clean image x₀ according to the schedule ᾱₜ:

xₜ = √ᾱₜ · x₀ + √(1 − ᾱₜ) · ε, where ε ~ N(0, I).

Using the provided alphas_cumprod, I implemented forward(im, t) to generate noisy versions of the Campanile at various timesteps, and visualized the increasing noise for t ∈ {250, 500, 750}.

1 — Training a Single-Step Denoising UNet

The goal of this section is to build a UNet-based denoiser that maps a noisy grayscale MNIST image z back to its clean version x by optimizing an L2 loss:

L(θ) = Ez,x ∥Dθ(z) − x∥²

The UNet architecture follows the diagram in the project handout, using Conv/DownConv/UpConv blocks, skip connections, and a flatten/unflatten bottleneck. All code is implemented in the provided Colab notebook.

2 — Training a Flow Matching Model

In this part I move to iterative denoising using a flow matching formulation. I define a linear path in data space between pure noise x₀ and a clean digit x₁, and train a time-conditioned UNet to predict the flow u(xt, t) = x₁ − x₀ along the path.

xt = (1 − t) x₀ + t x₁,   t ∈ [0, 1]

u(xt, t) = d xt / dt = x₁ − x₀

2.1 — Adding Time Conditioning to the UNet

I extend the UNet with fully-connected conditioning blocks (FCBlocks) that embed the scalar timestep t, and inject this conditioning into the unflatten and upsampling layers via multiplicative modulation as suggested in the handout.

2.2 — Training the Time-Conditioned UNet

I train the time-conditioned UNet using the flow matching loss:

L(θ) = Ex₀,x₁,t ∥(x₁ − x₀) − uθ(xt, t)∥²

Each batch samples a random clean digit x₁, a random noise sample x₀ ~ N(0, I), and a random timestep t ~ U[0,1]. I use batch size 64, Adam with learning rate 1e-2, and an exponential LR scheduler as described in the handout.
